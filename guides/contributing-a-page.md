# Writing a page for this wiki

1. Read the [rules](../CONTRIBUTING.md): no game material, describe tools and mods rather than storing them, a source
   and an evidence label on every fact.
2. Copy the right [template](../templates/) into the game's folder.
3. Fill what you can; write what you don't know as **Unknown** in an "Open questions" list.
4. Link to the shared [format pages](../formats/README.md) instead of repeating a format.
5. Update [STATUS.md](../STATUS.md).
6. Open a pull request.
