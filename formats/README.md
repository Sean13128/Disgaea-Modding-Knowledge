# File Formats

Formats that appear in more than one NIS game. Each page lists which games use it and links to the game pages.

| Format | Kind | Used by |
|---|---|---|
| [NISPACK](nispack.md) | Archive | Disgaea 5 (obfuscated), Disgaea D2 (big-endian tables inside), other NIS games |
| [NSAC](nsac.md) | Archive | Disgaea 4 (PC database and sprites; Vita) |
| [PS_FS_V1](ps_fs_v1.md) | Archive | Disgaea 5 (music), Disgaea 1 Complete (`SUBDATA.DAT`) |
| [FAFULLFS / FAFS](fafullfs.md) | Archive | Disgaea 5 (voices), Disgaea 4 (voices), Disgaea 6 (`data.dat`), Disgaea 7 (maps) |
| [DSARC FL / DSARCIDX](dsarc.md) | Archive | Disgaea 5 (sound effects), Disgaea DS |
| [YKCMP_V1](ykcmp.md) | Compression | Disgaea 5 (data, saves), Disgaea PC and Disgaea 2 PC (saves), Disgaea 6/7 |
| [Disgaea PC containers](disgaea-pc-containers.md) | PSPFS, OLA/COLA/SOLA, IMY, KM3, MPP, MPD, GEO, SH, TX2 | Disgaea PC (SH2 variant in Disgaea 2 PC) |
| [NIS LZS](nis-lzs.md) | Compression | Disgaea 4, 5, D2, 1 Complete (sprites, maps) |
| [anm](anm.md) | 2D sprite animation | Disgaea 4, 5, D2, 1 Complete |
| [Motion ids and what they mean](motion-names.md) | Animation ids across games | Disgaea 5, 4, D2, 1 Complete (names only in Disgaea RPG) |
| [Textures: TXF, TX2, TXP, NLTX, NMT](textures.md) | Images | Most games |
| [FAD, FANM](fad.md) | 2D illustration and animation containers | Disgaea 6, 7 |
| [OBF](obf.md) | 3D objects and effects | Disgaea 4, 5 |
| [NLSD](nlsd.md) | Sound | Disgaea 4 (variant), 6, 7 |
| [NMB / NMA](nmb-models.md) | 3D models, animations | Disgaea 6, 7 |
| [D5 maps](d5-maps.md) | Battle maps (.hex/.chr/.obf/.gop) | Disgaea 5 |
| [Portraits and faces](portraits-and-faces.md) | Character art | Every game: where cut-ins and faces live |
| [Save files](saves.md) | Saves | Every game: locations and formats |

Evidence for each claim is on the linked game pages.
