## A warning about fake tools

Searches for Disgaea trainers on GitHub turn up repositories that look generated: template text such as `{title}` in
the description, "ESP" or "aim" features that make no sense for a turn-based game, and a download link instead of
source. Those are a common way to spread malware. This catalog only lists projects with readable source or an
established forum thread. If a tool's download is hosted somewhere other than its own repository (as with
[Disgaea-7-Trainer](https://github.com/JellyfishCraft86/Disgaea-7-Trainer)), check what you're running.
