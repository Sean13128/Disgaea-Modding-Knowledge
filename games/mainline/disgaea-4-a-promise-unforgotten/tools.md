# Disgaea 4 — Tools

No public tool edits Disgaea 4 Complete+ (PC) files yet. These read them, or work on the console versions. For the
PS3 and Vita releases there is a public unpack/repack tool for the game's `.DAT` archives (below).

| Tool | Does | Versions | Status | License |
|---|---|---|---|---|
| D5 Mod Kit development fork (Sean13128): `d5lib/d4source.py`, `tools/d4_inspect.py`, `tools/d4_inventory.py` | **Reads** D4 tables, sprites, effects, voices and scripts to import them into Disgaea 5; inspects classes, evilities, skills and voices | Complete+ PC | Active, not in the public Kit yet | MIT |
| [Scarlet](https://github.com/xdanieldzd/Scarlet) (xdanieldzd) | Decodes TXF, NMT, NSAC, NISPACK, NIS LZS | PS3, Vita | Unmaintained | See repo |
| [NisAnim](https://github.com/xdanieldzd/NisAnim) (xdanieldzd) | Views and exports `.txf` images and `anm*.dat` animations | PS3 | Unmaintained | MIT |
| [Artina](https://github.com/xdanieldzd/Artina) (xdanieldzd) | Displays some D4 data files | PS3 | Unmaintained | MIT |
| [EASY-D4-DAT-UNPACK-REPACK](https://github.com/Glowtranslations/EASY-D4-DAT-UNPACK-REPACK) (Darkmet98 / Glowtranslations) | Decrypts and unpacks `.DAT` archives, then re-encrypts and repacks them; batch files around QuickBMS scripts by Raugo (PS3) and Luigi Auriemma (Vita). Made for a Spanish fan translation; instructions in Spanish | PS3, Vita | Old | GPL-3.0 |
| Trainers ([CheatHappens](https://www.cheathappens.com/72508-PC-Disgaea-4-Complete-trainer) and others) | Memory edits | Complete+ (Steam, Game Pass), version 09.13.2020 | Commercial | — |

Tools for Disgaea 5 (D5tools, D5 Mod Kit) target D5's NISPACK archives, not D4's NSAC ones, and won't open D4 files.
