# Disgaea 6 — Assets

| Asset | Where | Notes |
|---|---|---|
| 3D character models | `data/model.dat` | `.nmbm` models, `.nmba` animations, `.nltx` textures: [NMB / NMA format](../../../formats/nmb-models.md) (70 D6 models and 276 animations parsed) |
| Illustrations | [FAD](../../../formats/fad.md) texture tables in `data/data.dat` | Six-digit texture IDs match a model's four-digit character family |
| Text | `data/msg.dat` | |
| Voices, music, sound effects | `voice.dat`, `bgm.dat`, `se.dat` | |
