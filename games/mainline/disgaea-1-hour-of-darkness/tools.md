# Disgaea: Hour of Darkness — Tools

| Tool | Does | Edition | Status | License |
|---|---|---|---|---|
| [pg_disatools](https://github.com/ProgSys/pg_disatools) (ProgSys); [wiki](https://github.com/ProgSys/pg_disatools/wiki) with format pages (PSPFS, OLA/COLA/SOLA archives, SH sprite sheets, TX2, table files, NAME/TALK/SCRIPT.DAT, map files, MPP, GEO, KM3, IMY) and guides (installing mods, HD sprites, custom characters, translations, weapon sprites, memory allocation) | File Manager (`.DAT` / `.MPP`), Data Editor, Sprite Sheet Editor, TX2 Editor and converter, Map Editor, Mod Manager, DisaReverseEngineering (renderer hooks) | Disgaea PC | Active (v1.2.1 beta, 28 Oct 2026) | LGPL-3.0 (GUI), MIT (libraries, CLI) |
| DisaModManager (part of pg_disatools) | Installs pg_disatools' runtime module into the game and imports mod zips (characters, translations, campaigns) | Disgaea PC | Active (v0.3.7 beta) | LGPL-3.0 / MIT |
| [Pretty Prinny](https://github.com/Kaldaien/PrettyPrinny) (Kaldaien) | Render fixes: resolution cap, MSAA, SSAO, sprite smoothing | Disgaea PC (and Disgaea 2 PC) | Old | — |
| Disa PC File Manager, Unofficial Disgaea Tools (UDT) 0.9.8 alpha | Archive tools used to build the Netherworld Content Pack and the combined HD pack | Disgaea PC | Old | — |
| Netherworld Content Pack | Restores Disgaea DS content; edits `TALK.DAT` | Disgaea PC | Old | — |
| [disgaea-pc-tools](https://github.com/Xkeeper0/disgaea-pc-tools) (Xkeeper0) | Decrypt and decompress saves; read and edit units, items, innocents, senators; script and `DUNGEON.DAT` parsers. PHP | Disgaea PC | 2016 | MIT |
| [Pleinair](https://github.com/Darkmet98/Pleinair) (Darkmet98) | Translation tool: tables (`CHAR_E.DAT`, `TALK.DAT` …) and the executable's strings to and from `.po` files; `.FAD` archives | Disgaea PC (PSP, DS untested) | In development | GPL-3.0 |
| HenryEx's QuickBMS save script | Decode and re-pack saves | Disgaea PC (and Disgaea 2 PC) | Old | — |
| EdiZon config | Save editing | Disgaea 1 Complete (Switch) | — | — |
| [Disgaea-DS-Manager](https://github.com/Team-BrewSearch/Disgaea-DS-Manager) (NitroShellMKDS) | DSARC and MSND archive editor | Disgaea DS | — | See repo |
| [FireyFly's DS notes](https://gist.github.com/FireyFly/d9ef476107d8b11cbe7f) | File tree + C tools for DSARCIDX, DSARCFL, DATTBL | Disgaea DS | 2015 | — |
| D5 Mod Kit development fork: `d1cart.py`, `d1skill.py` | Reads D1 Complete sprites and both editions' `magic.dat` | Disgaea PC, D1 Complete | Active | MIT |
