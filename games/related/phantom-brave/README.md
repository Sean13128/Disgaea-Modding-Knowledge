# Phantom Brave

- **Released:** 2004 (PS2) · **Developer/publisher:** Nippon Ichi Software / NIS America
- **Versions:** PS2; Wii (*We Meet Again*); PSP (*The Hermuda Triangle*); **Phantom Brave PC** (Steam, July 2016); PS4 and
  Switch remasters. Sequel: **Phantom Brave: The Lost Hero** (2025: Switch, PS4, PS5; PC Steam April 24, 2025, with mouse
  and keyboard, up to 4K, ultrawide)
- **Modding status:** minimal: one text-fix mod for Phantom Brave PC; cheat tables for both PC games
- **Research on hand:** Minimal

## What's known
- **PS2:** a hidden debug menu with an edit mode exists, but EDIT doesn't work in international versions (TCRF).
- **Formats:** TX2 textures (PS2) and PSPFS_V1 archives (PSP), readable with [Scarlet](https://github.com/xdanieldzd/Scarlet).
  TX2 is also Disgaea PC's texture format. See [textures](../../../formats/textures.md) and [PS_FS_V1](../../../formats/ps_fs_v1.md).
- **PC (2016):** a Steam discussion describes extracting `DATA.DAT` with QuickBMS and fixing an inner archive's offsets
  by hand after rebuilding; the poster said the Disgaea tools worked too (**Community-reported**).
