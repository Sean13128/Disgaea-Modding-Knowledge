# Makaism: Frenzy of the Netherworld

**Same game as [Disgaea Mayhem](../../spin-offs/disgaea-mayhem/README.md).** *Kyouran Makaism* is the Japanese title,
*Makaism: Frenzy of the Netherworld* the Asian release (January 29, 2026), and *Disgaea Mayhem* the Western release
(July 23, 2026, including PC). Everything about it lives on the Disgaea Mayhem page.
