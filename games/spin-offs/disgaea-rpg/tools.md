# Disgaea RPG — Tools

| Tool | Does | License |
|---|---|---|
| [UnityPy](https://github.com/K0lb3/UnityPy) (K0lb3) | Reads Unity AssetBundles in Python: tables (`MonoBehaviour.DataList`), sprites, textures | MIT |
| [AssetStudio](https://github.com/Perfare/AssetStudio) (Perfare) | GUI explorer and exporter for Unity assets | MIT |
| D5 Mod Kit (`drpg.py`, `drpgmap.py`, `drpgsource.py`) | Builds D5 classes, monsters, characters and outfits from DRPG art | MIT |
| [Disgaea D2 native port](https://github.com/Sean13128/disgaea-d2-recomp) costume importer | Builds D2 costumes from DRPG art | MIT |

Use them on files from your own install.
