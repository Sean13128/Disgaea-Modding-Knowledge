# Disgaea RPG

- **Released:** 2019 (Japan, Android/iOS); Global later (also on PC via Steam) · **Developer:** Forwardworks / NIS
- **Versions covered here:** Japanese Android client 4.6.2, Unity 2022.3.62f2 (October 2026)
- **Modding status:** out of scope (online game). Its data and art are documented for reference and for other games' mods
- **Research on hand:** Medium
