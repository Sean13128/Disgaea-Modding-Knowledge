# Disgaea Mayhem

- **Released:** January 29, 2026 in Japan as *Kyouran Makaism* (PS5, Switch, Switch 2), and in Asia as *Makaism: Frenzy
  of the Netherworld*; **July 23, 2026** worldwide as *Disgaea Mayhem* (PS5, Switch 2, Switch, **PC Steam**)
- **Developer/publisher:** Nippon Ichi Software / NIS America
- **Genre:** action RPG spin-off (not a tactics game)
- **Modding status:** text extraction and rebuilding for translation ([triforce-disgaea](https://github.com/triforce-heroes/triforce-disgaea)); trainers exist ([CheatHappens](https://www.cheathappens.com/83274-PC-Disgaea_Mayhem_cheats))
- **Research on hand:** Minimal: [data.md](data.md) lists its 49 database tables and their record encoding (the D6 / D7 family)

No copy has been scanned for this project. Its database tables use the same record encoding as Disgaea 6 and 7
([data.md](data.md)), which points to the same engine family. Pages will be added from the
[templates](../../../templates/) once someone looks at the PC files.
