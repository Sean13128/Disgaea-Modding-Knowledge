# Disgaea D2: A Brighter Darkness — Tools

| Tool | Does | Platform | Status | License |
|---|---|---|---|---|
| [Disgaea D2 native port](https://github.com/Sean13128/disgaea-d2-recomp) (Sean13128) | Static recompilation of the PS3 game to native Apple Silicon code with a Metal renderer; Cheats menu, Item Editor, retail save import, costume importer and Sprite Workbench | macOS | Unmaintained (Oct 2026) | MIT |
| [Windows fork](https://github.com/LUUKASR1/disgaea-d2-recomp-windows) (LUUKASR1) | Windows launcher, Direct3D 12 renderer, direct ISO support | Windows | Active | See repo |
| [ps3recomp](https://github.com/sp00nznet/ps3recomp) (sp00nznet) | The recompiler and runtime the ports use | — | — | See repo |
| [RPCS3](https://rpcs3.net/) | PS3 emulator; used to install firmware, update and DLC and to decrypt `EBOOT.BIN` | Windows, macOS, Linux | Active | GPL-2.0 |
| RPCS3 game patches | Memory patches applied by the emulator at runtime (e.g. a community performance patch) | RPCS3 | Community | — |
| [pfdtool](https://github.com/SteffenL/pfdtool), [Apollo Save Tool](https://github.com/bucanero/apollo-ps3) (bucanero) | PS3 save decryption and patching | PS3 / PC | — | See repos |
| D5 Mod Kit development fork: `dd2source.py` | Reads D2's tables to import classes into Disgaea 5 | — | Active | MIT |

All of these need **your own** game dump. None ships game files.
