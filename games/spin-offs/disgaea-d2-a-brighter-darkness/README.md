# Disgaea D2: A Brighter Darkness

- **Released:** 2013 (PS3) · **Developer/publisher:** Nippon Ichi Software / NIS America
- **Versions covered here:** PS3 North America (BLUS31313), update 1.40 and DLC. Also the fan-made native ports (macOS, Windows)
- **Modding status:** none for the PS3 release; feature work (cheats, item editor, costumes) happens in the native port
- **Research on hand:** Medium

## Start here
- **Play or mod it on a computer:** the [native port](https://github.com/Sean13128/disgaea-d2-recomp) (Mac) or its [Windows fork](https://github.com/LUUKASR1/disgaea-d2-recomp-windows), with your own dump. See [tools.md](tools.md).
- **Understand the files:** [INDEX.md](INDEX.md) → [data.md](data.md).
